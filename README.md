## 🚀 Projetos em Andamento

### 🧩 Nexus &nbsp; ![Status](https://img.shields.io/badge/Status-Em%20MVP-orange?style=flat-square) ![Início](https://img.shields.io/badge/Início-Jan%202026-lightgrey?style=flat-square)

Software para garantir a confiabilidade, extração e manipulação de elementos BIM. Oferece visibilidade sobre o percentual e o progresso da obra a partir dos parâmetros extraídos de modelos 3D.

Dentro do **Navisworks** extrai parâmetros via C#; externamente, uma interface Python permite manipular e editar as informações, gerando uma planilha completa ao final.

> `C#` `Python` `BIM` `Navisworks` `Autodesk`

### 🗺️ Atlas &nbsp; ![Status](https://img.shields.io/badge/Status-Deploy%20Concluído-brightgreen?style=flat-square) ![Início](https://img.shields.io/badge/Início-Set%202025-lightgrey?style=flat-square) ![Patches](https://img.shields.io/badge/Patches-Mensais-lightgrey?style=flat-square)

Identificar modelos 3D desatualizados em modelos federados era um processo manual e lento. O Atlas automatiza essa análise: compara a data de modificação dos caches a partir dos arquivos nativos, permitindo marcar uma ou várias pastas no diretório e resumindo os resultados em planilha ou via interface.

> `Python` `Autodesk` `BIM` `Automação`
